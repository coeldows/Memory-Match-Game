# 🎮 Memory Match Game

A fast, fun, and nostalgic memory matching game designed for web browsers — especially engaging for 30–50 year olds who love a retro twist.

### 🧠 What It Is
Match pairs of emoji cards inspired by old-school tech and pop culture — floppy disks, VHS tapes, cassette players, and more. Great for a quick brain boost or a throwback trip down memory lane.

### 💡 Features
- Simple, clean browser-based interface
- 8 pairs of emoji cards shuffled each game
- Responsive layout with instant gameplay
- Retro-themed for a fun, nostalgic vibe

### 🚀 How to Play
1. Click on any two cards to reveal them.
2. If they match — great! They stay flipped.
3. If not — they flip back after a second.
4. Match all 8 pairs to win!

### 🔧 To Use
1. Clone or download this repository.
2. Open `index.html` in any web browser.
3. Start matching and enjoy!
